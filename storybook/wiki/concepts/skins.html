Skins System

Appearance customization system for FDE Desktop with two independent axes: color skins and window control styles. Both are selected separately and can be combined freely.

Overview

The system separates two concerns that were previously coupled:

AxisWhat it controlsStored in
Color skinDesktop, window, taskbar, accent colors + border radiusactiveSkinId
Window control styleMinimize / maximize / close buttonswindowControlStyle

This means you can combine any color skin with any window control style (e.g. Dracula colors + Win93 buttons).

Settings Store

Selecting a color skin syncs the theme mode (light/dark) but does not reset windowControlStyle. Both settings are fully independent.

Auto-selection on control style change

Selecting a window control style automatically activates the canonical color skin for the current theme mode:

Control styleDark skinLight skin
classicdefaultmonokai-light
macosdefaultmonokai-light
win93win93-darkwin93

This is implemented in setWindowControlStyle in settingsStore.ts via CONTROL_STYLE_DEFAULT_SKINS.

Theme Provider Integration

ThemeProvider reads the active skin and merges colors with priority:

customThemeColors > theme colors > skin colors > base theme

CSS variables from skin.cssVars are injected into :root via useEffect.

Testing

Unit tests (Vitest)

  • packages/core/src/components/Shared/WindowControlStyles.test.tsx — win93 and winXD control rendering + click handlers
  • packages/core/tests/skins/index.test.ts — skin registry, getSkinById, getAllSkins
  • packages/core/tests/skins/skins.cssVars.test.ts — CSS var contracts: --color-title-bar-text, --color-surface-subtle, border radius, mode consistency
  • packages/core/tests/Theme/useSkin.skin.test.tsx — useSkin, useWindowControls, useWindowControlStyle hooks

Playwright integration tests

Located in tests/integration/skins-theme-sync.integration.spec.ts. These tests verify skin application via live CSS vars on document.documentElement.style — no localStorage reads, no Settings persist complications.

Key patterns used:

Coverage:

  • Skin + theme mode synchronization (win93/winxd in light and dark mode)
  • setWindowControlStyle → auto-selects canonical skin
  • Classic control style → clears retro CSS var overrides
  • Theme toggle keeps skin in sync (win93 dark↔light, winxd dark↔light)
  • --color-title-bar-text applied per skin
  • Skin CSS vars applied to DOM on startup (localStorage persistence)
  • Skin + window control style independence

Playwright visual tests

Located in tests/visual/skins/retro-skins.visual.spec.ts. All tests use setupWithSkin() to pre-load skin state via localStorage before page load, avoiding Settings UI complications.

Coverage:

  • Title bar snapshot per skin (win93, win93-dark, winxd, winxd-dark) — maxDiffPixelRatio: 0.1
  • Window control styles snapshot per style via titlebar — maxDiffPixelRatio: 0.1
  • Full desktop snapshot per skin — maxDiffPixelRatio: 0.4 (wallpaper/clock variance)
  • Title bar text contrast verification: dark-bg skins → luminance > 100, light-bg skins → luminance < 155
