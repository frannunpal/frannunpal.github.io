Ink Chat App

@fde-desktop/ink — Narrative engine package based on inkjs (Inkle’s scripting language for interactive fiction), wrapped in hexagonal architecture. Integrates as an app in fde-desktop via registerInkChatApp().

Application Layer

IStoryEngine (port interface)

StoryEngineService

Orchestrates engine lifecycle. Key behaviors:

  • Calls initialize(storyJson) on first access
  • Sets up observer subscription → state updates
  • continue({ maximally: true }) runs all content until next choice or story end
  • save() returns JSON string of full story state
  • load(json) restores from saved JSON

Infrastructure: InkJsAdapter

Wraps inkjs Story class. Key implementation details:

Initialization

Continue (Maximally)

Choice ID Format

Choices use string IDs formatted as choice-{index} where index is the 0-based position in story.currentChoices. The adapter parses this back to index in makeChoice().

Save/Load

Uses inkjs’s built-in state serialization. Note: requires the original story JSON to have been loaded first for LoadJson to work (inkjs recreates the full state from the initial story + the serialized divergent state).

Error Handling

All public methods are wrapped in try/catch. Errors are classified:

  • PARSE_ERROR — JSON parsing or Story constructor failure (non-recoverable)
  • RUNTIME_ERROR — Failures during Continue() (recoverable)
  • CHOICE_ERROR — Invalid choice index (non-recoverable)
  • STATE_ERROR — Save/load failures (non-recoverable)

Errors are captured as StoryError in state, and all observers are notified via { type: 'ERROR', error: StoryError }.

Presentation Layer

useInkStory(storyJson: object)

Main hook for consuming stories:

Key behaviors:

  • Instantiates StoryEngineService(new InkJsAdapter()) once via useState
  • Calls initialize(storyJson) in useEffect
  • Auto-continues on init to get first content
  • Subscribes to engine state changes via observer pattern
  • reset() destroys engine + forces re-init via initKey counter

useInkStoryPersistence(storyId: string)

Auto-saves story state to localStorage. Returns:

Backed by Zustand persist middleware under key 'fde-desktop:ink-story'.

InkChatApp Component

Props:

PropTypeDefaultDescription
storyJsonobjectdefaultStoryJsonInkle JSON story data
storyIdstring’default-story’Unique ID for persistence
typingDelaynumber800Typing animation delay (ms)
enableActionButtonsbooleantrueShow action buttons from action: tags
autoSavebooleantrueAuto-persist story state

UI features:

  • Typing indicator: Shows “{Speaker} is typing…” during message delay
  • Choice buttons: Displayed as story choices (story mode)
  • Action buttons: Extracted from #action:hunt / #action:think / #action:plan / #action:wait tags (hunt, think, plan, wait)
  • Two input modes: ‘story’ (choices/buttons) or ‘chat’ (freeform text input)
  • Error alert with Retry button
  • Auto-save/load via useInkStoryPersistence
  • Notifications on choice arrival and runtime warnings
  • Avatar colors per speaker via useFdeAvatarColor
  • Window menu bar integration: story controls in menu

InkChatAppMenuBar

Provides menu bar for story controls:

  • Reset Story — destroys and reloads story state
  • Clear History — clears display history (not story state)
  • Load/Save controls

useFdeAvatarColor

Derives deterministic colors from speaker names using a seeded hash against a fixed palette. Ensures each character always has the same color.
