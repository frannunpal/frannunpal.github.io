Singleton exports

useSettingsStore

User preferences (persisted as fde-desktop:settings).

PropertyTypeDescription
wallpaperstring | nullBackground image URL
fontstringSelected font family
fontSizenumberUI font size in px
animationDurationnumberFramer Motion multiplier
themeThemeCurrent theme object
languageSupportedLanguage'en' | 'es'

Key actions: setWallpaper, setFont, setFontSize, setThemeMode, toggleTheme, setLanguage, setAnimationDuration.

useCustomAppStore

Manages dynamic apps in Docker mode.

Property / ActionDescription
customAppsLoaded custom app manifests
isLoadingLoading state
loadCustomAppsFetch from /api/apps
registerAppRegister a custom app at runtime
unregisterAppRemove a custom app

useAppTempMemoryStore

Temporary snapshots for dirty-state tracking (persisted as fde-desktop:appTempMemory).
