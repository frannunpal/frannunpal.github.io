SunStudyApp

Independent app for real-time sun study and lighting simulation on a Mapbox basemap. Split from CitiesTheatre — has its own store, hooks, and components. No deck.gl 3D city rendering, only Mapbox native lighting.

Setters

Factory-generated simple setters (setSunAngle, setTimeOfDay, etc.) plus two special:

  • setSimulationDate(date: string | null)
  • setFlyToTarget(target: ViewState | null)

Lighting System

Synced every frame via useEffect. Uses Mapbox map.setLights() API (not deck.gl LightingEffect).

Mapbox Directions

Mapbox directional light uses direction: [azimuthDeg, polarDeg] where:

  • azimuthDeg = sunAngle (0-360°)
  • polarDeg = 90 - sunElevation (clamped 0-90)

This differs from deck.gl’s DirectionalLight which uses Cartesian XYZ in Z-up.

Hooks

useSunDayNightCycle()

Drives the sun position from timeOfDay + simulationDate using SunCalculationService.getSunAnglesFromTimeOfDayAndCoords(). Updates sunAngle, sunElevation, ambientIntensity, directionalIntensity in the store each frame. Also handles real-time mode (useRealTime) using the actual clock.

useSunMapControls(options)

Provides camera state, Mapbox map ref, and container ref for the <Map> component.

useDeckGlWidgets()

Returns only the passive FPS StatsWidget from @deck.gl/widgets. No interactive widgets (incompatible with MapboxOverlay).

Sub-components

SunStudyTimeControls

Floating overlay panel (positioned absolute over the map) with:

  • Time slider (0-1440 minutes, wraps at midnight)
  • Date picker (for simulationDate)
  • Playback controls: play/pause, speed multiplier
  • Real-time toggle
  • Current sun angle/elevation readout

GeocoderControl

Implements mapbox-gl-geocoder via useControl for searching locations. Updates camLat/camLon on selection. Only renders when Mapbox token is available.

MapControls

React-based map controls (not Mapbox GL native DOM buttons):

  • Zoom +/− buttons
  • Reset North button (resets bearing to 0)
  • Implemented as Mantine ActionIcon components

DeckGLOverlay

Minimal MapboxOverlay wrapper that holds deck.gl widgets (StatsWidget). Necessary because deck.gl widgets require a Deck instance and MapboxOverlay provides the interop.

Dependencies

  • react-map-gl/mapbox — Map component
  • @deck.gl/core — StatsWidget via MapboxOverlay
  • @mapbox/mapbox-gl-geocoder — search UI
  • VITE_MAPBOX_TOKEN — env var for Mapbox access token
